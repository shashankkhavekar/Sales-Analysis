# 📊 Sales Analysis Project

## 📌 Project Overview
The Sales Analysis project focuses on analyzing sales data using Python, SQL, PostgreSQL, and Power BI. The goal is to understand sales performance, analyze product quantities, identify trends over time, and present meaningful business insights through an interactive dashboard.

## 🎯 Objectives
- Analyze overall sales performance.
- Calculate total sales and product quantities.
- Identify daily and monthly sales trends.
- Compare the performance of different products.
- Create an interactive dashboard for data-driven decision-making.

## 🛠️ Tools & Technologies
- **Python:** Data cleaning and data manipulation.
- **Pandas:** Data processing and transformation.
- **SQL:** Data analysis using queries and aggregate functions.
- **PostgreSQL:** Database storage and querying.
- **Power BI:** Interactive dashboard creation and visualization.

## 📂 Dataset Description
The dataset contains daily sales and quantity information for four products.

**Columns used:**
- `Date` – Date of the sales record.
- `Q-P1`, `Q-P2`, `Q-P3`, `Q-P4` – Quantity sold for each product.
- `S-P1`, `S-P2`, `S-P3`, `S-P4` – Sales amount for each product.

## 🔄 Project Workflow

### 1. Data Cleaning Using Python
- Loaded and explored the dataset using Pandas.
- Checked data quality and prepared the data for analysis.
- Performed data manipulation to make the dataset suitable for further analysis.

### 2. SQL Analysis Using PostgreSQL
- Retrieved and explored sales records.
- Calculated total quantities sold for each product.
- Calculated total sales for each product.
- Analyzed sales performance by date.
- Categorized sales performance into High, Medium, and Low levels.
- Analyzed monthly sales trends using date functions.

### 3. Power BI Dashboard
- Connected PostgreSQL to Power BI.
- Created KPI cards to display key sales metrics.
- Designed daily and monthly sales trend charts.
- Added slicers to filter and explore the data.
- Used visualizations to compare product sales and quantities.

## 📈 Key Performance Indicators (KPIs)
- Total Sales
- Average Sales
- Total Quantity Sold
- Number of Sales Days
- Sales Performance

## 💡 Key Learnings
- Data cleaning and manipulation using Python.
- Writing SQL queries for business analysis.
- Working with PostgreSQL databases.
- Creating interactive dashboards in Power BI.
- Understanding sales trends and performance metrics.
- Presenting data insights through visualizations.
